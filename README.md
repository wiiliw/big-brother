# 大哥定价思维框架

从政策、国有资本与市场数据的关系研究A股。保留“大哥视角”的六个模型，但把它们作为可验证的假设，不代言监管机构，不预设内部点位和交易计划。

## 六个研究模型

| 模型 | 研究问题 |
|---|---|
| 波动率优先 | 波动、杠杆与流动性如何影响市场稳定？ |
| 股权财政接力 | 国有资产运营能带来多少实际财政现金流？ |
| 定价权差序格局 | 不同资金的规模、持仓和约束如何影响价格？ |
| 估值名实分离 | 战略作用如何转化为可验证的盈利与现金流假设？ |
| 礼治窗口指导 | 哪些是正式规则，哪些是有来源的沟通信号？ |
| 无为政治 | 公开政策行动的条件、时点和退出安排是什么？ |

《乡土中国》的相关概念仅作类比，不能替代资本市场证据。市值管理政策不等于股价保证，国资背景不等于所有公司都受相同考核。

## 使用方式

Skill入口为[SKILL.md](SKILL.md)。使用支持本地Skill的工具时，安装整个仓库，保留配套资料和相对目录。现有Claude环境可放入 `~/.claude/skills/dage-skill/`，具体触发方式以所用工具为准。

问题示例：

- 从国家队公开动作和ETF数据看，哪些判断有依据？
- 这家央企的分红、估值和市值管理政策如何相互影响？
- 地方国资股权收益能否改善财政现金流，需要哪些证据？

回答应先查事实，再给机制、替代解释和失效条件。有关当前市场的问题需重新获取数据，不从历史快照直接推导买卖点。

## 维护与检查

本项目是研究资料库，不是实时行情或完整国资证券数据库。角色语言与政策意图属于分析假设，事实引用以原始公告为准。

- [维护指南](CONTRIBUTING.md)：更新流程与验收。
- [资料台账](docs/catalog.json)：历史截止日期、核验状态和复核周期。
- [核验记录](docs/FACT_CHECKS.md)：本次纠错与待查事项。
- [2026陆家嘴论坛](2026陆家嘴论坛.md)：对照部门原文的选择性摘要，政策状态截至会议当日。

本地要求 Python 3.10+，无需第三方依赖：

```bash
python3 scripts/check.py
python3 -m unittest discover -s tests -v
```

检查文件、仓库内 Markdown 文件链接、资料台账、Skill入口与股票代码格式；不联网验证事实，也不检查标题锚点。历史资料过期提示不阻断普通提交；`python3 scripts/check.py --strict` 将待复核和过期提示视为失败。GitHub Actions 在推送、PR、每周和手动触发时运行并保存报告。
