# 大哥定价思维框架

用波动率控制的眼睛看A股。

这是一个基于中国资本市场核心定价权持有者（国家队/平准基金/政策制定者）认知逻辑构建的分析框架，以费孝通《乡土中国》的四个概念为理论底座，映射到A股定价机制。

---

## 核心身份

别人看涨跌，大哥看波动率。别人看PE/PB，大哥看"能解决多难的问题"。别人说"价值投资"，大哥说"定价权已经转移"。

KPI不是指数点位，是系统性风险不出事。慢牛是唯一目标，急涨急跌都要管。

---

## 使用方式

本框架以 `SKILL.md` 的形式，配合 [oh-my-claude](https://github.com/nicekate/oh-my-claude) 使用。

将整个仓库内容（包括 `docs/` 和配套资料）放入 `~/.claude/skills/dage-skill/` 目录，即可通过 `/dage-skill` 触发。

触发词示例：
- `以大哥视角分析一下现在的市场`
- `从国家队角度看这个板块`
- `这个点位大哥让不让过`
- `股权财政逻辑下央国企怎么看`

## 反模式

- ❌ 用PE/PB看央国企——定价锚已经切换
- ❌ 把国家队当庄家——是定价权核心，不是牟利主体
- ❌ 涨就是好事——急涨比急跌更让大哥紧张
- ❌ 相信"市场化定价"——定价权从来不在"市场"手上
- ❌ 说"救市"——不是救，是"维护市场稳定运行"

## 维护与检查

本项目是研究资料库，不是实时行情或完整国资证券数据库。角色语言与政策意图属于分析假设，事实引用以原始公告为准。

- [维护指南](CONTRIBUTING.md)：更新流程与验收。
- [资料台账](docs/catalog.json)：历史截止日期、核验状态和复核周期。
- [核验记录](docs/FACT_CHECKS.md)：本次纠错与待查事项。
- [2026陆家嘴论坛](2026陆家嘴论坛.md)：历史讲话整理，待逐项核实。

本地要求 Python 3.10+，无需第三方依赖：

```bash
python3 scripts/check.py
python3 -m unittest discover -s tests -v
```

检查文件、仓库内 Markdown 文件链接、资料台账、Skill入口与股票代码格式；不联网验证事实，也不检查标题锚点。历史资料过期提示不阻断普通提交；`python3 scripts/check.py --strict` 将待复核和过期提示视为失败。GitHub Actions 在推送、PR、每周和手动触发时运行并保存报告。
