# 证据台账

`reviewed_claims.csv` 保存具体核查结论，不是完整证券主表。UTF-8 BOM便于中文电子表格软件读取，证券代码保留交易所后缀及前导零。

| 字段 | 含义 |
|---|---|
| id | 稳定引用编号，新增顺延，不重用 |
| code | 证券代码；政策事项用“—”，REIT代码不视为股票 |
| claim | 本条证据支持的具体结论，不能扩展到未核字段 |
| evidence_date | 事实生效日或报告截止日，具体语义见结论；不统一当作公告日 |
| checked_on | 人工查阅日期，不代表已查完此日之前全部公告 |
| source_url | 公司披露、交易所、监管或集团来源；部分链接为原公告的第三方承载页 |

更新时同步[人读核查记录](../docs/REVIEW_2026-09-17.md)与相应正文。出现新变化应保留历史事件，新增证据说明替代关系，不覆盖旧日期。代码核验、控制核验与上市状态核验须分别表述。
