# 市场与财政数据：快照和计算口径

查阅日期2026-09-17。以下为本次取得的一手资料，不是实时行情服务。讲话数据按讲话时点保存，不能据此填写今日指数或资金流向。官方统计一般有披露时滞；本页不声称所有指标都已更新至最新一期。

可复算的比较：

- 2024较2021土地出让收入下降：`1 - 48699 / 87051 = 44.06%`。原稿“2024已腰斩”不精确。
- 2025较2021下降：`1 - 41518 / 87051 = 52.31%`。约减半在此期间才成立。
- 2025地方国有资本经营预算本级收入与当年土地出让收入之比：`4644 / 41518 = 11.19%`。这只是两个预算收入项目的规模比较，不是替代率、投资回报率或可用于填补缺口的净额；二者相关支出也不同。

这些数据支持继续研究地方财源变化，但不能证明提高股票估值即可补足财政缺口。公募净值规模也不足以证明任何一类资金垄断定价权。

## 容易误读的历史数字

2026年6月基金业大会讲话中的**13.4万亿元**是基金行业股票投资规模，**超过39万亿元**才是公募规模，不能拼成“公募股票持仓13.4万亿”。[证监会转载讲话](https://www.csrc.gov.cn/qingdao/c105643/c7638284/content.shtml)

2025年保险权益配置通知按上季末综合偿付能力充足率分档：低于100%、100%至不足150%、150%至不足250%、250%至不足350%、350%及以上，对应权益类资产账面余额占上季末总资产上限分别为10%、20%、30%、40%、50%。其他约束仍需按适用规则核查；不能把最高档上限写成全行业必须买入A股50%。[通知官方转载](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=102306)

## 当期市场分析怎么补数据

| 目的 | 推荐输入和计算 | 校验 |
|---|---|---|
| 波动与回撤 | 同一指数日收盘；`r_t = ln(P_t/P_(t-1))`；20/60日`std(r, ddof=1) × sqrt(252)`；回撤`P_t/历史峰值-1` | 至少窗口长度加1个收盘价；按交易日排序去重；缺失值不当0 |
| 活跃度 | 同范围成交额近三年分位、成交额/流通市值 | 区分股票与ETF、沪深与沪深北；不混成交股数与金额 |
| ETF净申赎估算 | 调整折算后的份额变化×同日净值，注明是估算 | 不能直接用资产净值增减代替流入流出；二级市场成交与一级申赎分开 |
| 特定持有人行为 | 同一持有人、同一基金、相邻披露期持有份额 | 年报/半年报期末快照不能还原逐日交易，更不能推出未来计划 |
| 估值比较 | 同定义PE/PB与行业/自身历史区间，结合ROE、现金流和负债 | 亏损、负净资产、周期高点利润及指数样本变化单独处理 |

本次未取得并复算一套完整、同口径的每日指数序列及全部汇金持仓底表，故不发布今日波动分位、买卖点或汇金总仓位。原稿1.05万亿、1.53万亿、“计划减持90%”不作为已核市场事实继续使用；这不等于已经证明某一时期没有减持。
